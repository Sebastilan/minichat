# MiniChat · 最简对话助手

约 440 行 Python(标准库,零依赖)做一个有长期记忆的微信私人助手。核心只有四件事:

| | 做什么 | 文件 |
|---|---|---|
| 收发 | 微信官方机器人接口(iLink)扫码绑定、收消息、回复;也能在命令行里聊,不用微信也能演示 | `wechat.py` `main.py` |
| 问 | 简单问题直接答;复杂需求先按 **输入 / 输出 / 目标 / 约束** 四要素逐项问清,复述【问题定义】确认后再做 | `prompt_chat.md` |
| 答 | 多模型:OpenAI 兼容和 Anthropic 两种协议覆盖绝大多数厂商;配置里加一行就接一家,`/模型 名字` 切换,失败自动换下一个 | `models.py` |
| 记 | 睡眠整理:聊完静默几分钟,把新聊天整理成记忆卡片 + 索引;五星卡每次都带上,其余看索引一两步读到 | `sleep.py` `memory.py` `brain.py` |

## 快速开始

```bash
python3 main.py selftest          # 离线自检(假模型,不联网),看到 selftest ok 即可
cp models.example.json models.json # 留下你要用的模型,排第一个的是默认
cp .env.example .env               # 填对应的 API Key
python3 main.py                    # 命令行对话;/退出 时自动整理一次记忆
```

需要 Python ≥ 3.9。

### 接微信

要求:个人微信 ≥ 8.0.70,且已在「我 → 设置 → 插件 → ClawBot」灰度范围内。

```bash
python3 main.py login    # 打印二维码链接:电脑浏览器打开,用要绑定的微信扫码并在手机上确认;要求输数字就照手机上的输
python3 main.py wechat   # 开始收发;给这个 bot 发一句话试试
```

绑定后每个给 bot 发消息的人各有一份独立的聊天和记忆(目录名是用户 ID 的哈希)。

### 聊天里可用的命令

`/模型 名字` 切换 · `/模型列表` · `/记忆` 看记忆索引 · `/睡` 立刻整理 · `/帮助`

### 定时整理(可选)

微信模式下静默 `SLEEP_IDLE_MIN` 分钟(默认 5)会自动整理;也可以交给 cron:`python3 main.py sleep`。

## 记忆怎么存

```
data/<用户>/
  chat.jsonl            聊天记录
  state.json            当前模型、整理到第几行
  memory/
    index.md            索引:一行一卡「★星级 路径 — 一句话」
    <主题>[/<子主题>]/<名>.md   卡片:头三行 星级/更新/一句话,正文 ≤200 字
    _退/                退掉的卡(只挪不删)
  archive/<时间>/       每次整理前的整份存档
data/_bots/<bot>.json   微信 bot 凭证(权限 600)
```

- **预加载**:系统提示里只放所有五星卡正文(≤800 字)+ 整份索引(≤1500 字)。
- **一两步可达**:模型要用别的卡时回一行 `读记忆: 路径`,程序读卡再问一次,最多两次。纯文本约定,任何模型都能用,不需要工具调用或向量库。
- **防误删**:整理只能出 新卡/改卡/退卡/调星 四种操作;改卡、退卡必须一字不差引用户在新聊天里的原话,否则拒绝;主题最多三层。

## 限制

- 微信侧只支持私聊,不能进群;用户超过 24 小时没说话,主动发的消息会被丢,所以本项目不做主动推送。
- 只处理文字和语音(用微信给的转写),图片、文件暂不支持。
- 只用非流式纯文本对话,不用各家的工具调用。
- 数据全在本机 `data/`,已写进 `.gitignore`;不要把 `.env`、`models.json`、`data/` 提交到任何地方。

## 协议依据

iLink 接口按腾讯 `Tencent/openclaw-weixin` 仓库 `docs/protocol_zh_CN.md`(MIT)实现;`channel_version` 前三段须是官方插件版本(本项目报 `3.0.0/minichat-0.1.0`)。
